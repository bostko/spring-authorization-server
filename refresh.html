● What is a Public Client?

  A public client (RFC 6749 §2.1) is an OAuth2 client that cannot keep a secret — typically:
  - Single-Page Applications (SPAs) running in the browser
  - Native/mobile apps

  It authenticates with client_authentication_method = none, meaning no client_secret is sent. PKCE is used
   instead to prove identity.

  A confidential client (server-side web app, backend service) can store a client_secret securely.

  ---
  Why does Spring block refresh tokens for public clients by default?

  The concern is token theft: if a refresh_token is stolen from a public client's storage (e.g.,
  localStorage), the attacker can silently get new access tokens indefinitely. Confidential clients can
  rotate secrets; public clients cannot.
